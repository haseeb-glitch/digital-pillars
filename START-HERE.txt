DIGITAL PILLARS — UPDATED WEBSITE PACKAGE

QUICK PREVIEW
1. Extract this ZIP.
2. Open OPEN-WEBSITE.html in a modern browser.
All styles, JavaScript and artwork are embedded. No installation is needed.

EDITABLE SOURCE
src/App.tsx — content, page sections, dashboards and interactions.
src/styles.css — glass effects, layouts, responsive rules and animations.
components/testimonials.tsx — six editable review cards and carousel.
components/ui/ — accessible dialogs, navigation sheets and FAQ accordion.
public/images/ — optimized artwork, including the portrait city backdrop.
scripts/build-standalone.mjs — recreates the self-contained HTML preview.

RUN AND EDIT
Install Node.js 22.13 or newer. In this folder, run:
  npm install
  npm run dev
Open the local address shown by the terminal.

BUILD
  npm run build
This rebuilds dist/ and OPEN-WEBSITE.html.
  npm run preview
The included dist/ is ready for a static host at the domain root.
A pnpm lockfile is included for pnpm users.

REFERENCE AND CONTENT
This recreates the portrait video composition and preserves useful sections
from the existing website. The AI-generated video changes shapes and text
between frames; this is a coherent visual recreation, not a pixel-exact copy.
The original source, fonts and artwork were not provided.
Unreadable reference text is represented by editable, readable sample copy.
Names, testimonials, ratings, metrics and project examples are sample content.
The login dialog is a placeholder; authentication is not connected.
The FAQ uses fixed answers. The brief form downloads a local text file.
No brief is emailed or submitted to a server.
